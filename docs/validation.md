## Speaker accuracy and source-camera cuts

Inspected the owner's 47.63-second portrait export. It contains intermittent crops beside/partly outside faces and frequent changes of camera angle. The previous tracker discarded identities on every missed detection, matched only by horizontal position, included face size in speech activity, and did not reset its crop at source-camera changes. It could smooth an old position into a new shot. A new real-face render regression also exposed millisecond timestamp rounding postponing the crop by one frame at a 17/30-second camera cut.

Tracking version 3 bundles the 232,589-byte YuNet face/landmark model through the existing OpenCV CPU runtime. Its bytes match OpenCV Zoo's published Git LFS SHA-256; provenance and both upstream license notices are included. No runtime network download, new dependency, or paid API is needed. Faces are matched in two dimensions with scale constraints and retained briefly across missed detections. Lip patches are aligned using facial landmarks; illumination, small image shifts, and upper-face movement are discounted. Size is only an initial tie-breaker, and brief occlusions/weak ambiguous motion retain the existing speaker. Analysis starts independently at source-camera cuts, with observed boundaries refined to the source frame grid. Rendering no longer rounds the runtime crop command past a frame boundary. Existing speaker metadata is upgraded once when re-exported.
